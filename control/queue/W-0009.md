## Objective
Make independent review before merge enforced by GitHub itself, so agent merges in non-production repositories need no owner click and no local process can bypass the check.

## Context
Redesigned in W-0014 after the repository became public with no-bypass rulesets. The Actions `merge-gate` approach was rejected: same-repository PRs can fake a workflow-reported check. The new design is native: a separate non-admin machine account for Claude, plus `required_approving_review_count: 1` and `require_last_push_approval`. Full design and rationale: `docs/AGENT_IDENTITY.md`.

## Owner steps
See `docs/AGENT_IDENTITY.md` "Owner steps":
1. create the machine account (2FA, email privacy);
2. invite it with Write;
3. log Claude's `gh` in as it, removing the owner token from Claude's environment;
4. authorize or apply the ruleset change.

## Acceptance criteria
- Claude's `gh` identity is the machine account, without admin rights.
- `protect-main` requires one approving review with last-push approval and has no bypass actors.
- Demonstrated on a throwaway PR: Claude can't approve its own PR, and an unapproved PR can't be merged.
- Then, via a reviewed PR, `gh pr merge` moves to allow for non-production projects; W-0007 is closed as satisfied.
